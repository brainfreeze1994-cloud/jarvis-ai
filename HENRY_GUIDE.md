## Getting Started

### Web App
1. Open your HENRY URL in any browser (Chrome recommended)
2. Click **Install** or **Add to Home Screen** when prompted — HENRY works offline too
3. Allow **microphone permission** when asked
4. Tap the **orb** or the **🎤 mic button** to speak, or type in the input box and press Send

### Android App
1. Install the APK (allow Unknown Sources if prompted)
2. Open HENRY — the splash screen loads
3. Grant all permissions when prompted (microphone, camera, contacts, storage)
4. Tap the **orb** or mic button to start talking

## Talking to HENRY

HENRY understands **natural language** — just speak or type normally.

### Wake Word (Web)
Enable wake word mode and say **"HENRY"** — he will start listening automatically without tapping anything.

### Response Modes
HENRY has 3 response lengths:
| Mode | Use when |
|---|---|
| **Brief** | Quick facts, one-liners |
| **Balanced** | General conversation (default) |
| **Detailed** | Research, explanations, step-by-step |

Say *"give me a detailed answer"* or *"keep it short"* to switch.

## Tips & Tricks

1. **Chain commands** — *"Check the weather and then tell me today's news"*
2. **Give context** — *"I'm going to a job interview. How should I prepare?"*
3. **Use follow-up chips** — after a reply, HENRY suggests related questions — tap them
4. **Long-press chips** (Android) — edit the suggestion text to customise
5. **Attach before asking** — attach an image first, then ask your question
6. **Tagalog works** — just write or speak in Filipino and HENRY replies in Filipino
7. **Wake word** — enable and just say "HENRY" from anywhere in the app
8. **Memory** — the more you talk to HENRY, the better he knows you
9. **Offline** — install as PWA for offline access to brain modules and memory

## Troubleshooting

| Problem | Fix |
|---|---|
| No voice / silent | Check browser microphone permission |
| "All systems resting" | Daily AI limit reached — wait or try again in minutes |
| Map not loading | Allow JavaScript; check internet connection |
| Voice sounds robotic | Switch accent in VOICE settings |
| Image not recognised | Use JPG under 2MB; retry once |
| Android TTS silent | Go to Settings → Text-to-speech → install Google TTS |

---

## Rate Limits & What to Expect

HENRY uses a 5-provider AI cascade. If one provider's daily limit is reached, he automatically tries the next. You will almost never hit a dead end.

- **Normal usage** (< 100 messages/day): Always available
- **Heavy usage** (100–500 messages/day): May switch providers mid-day
- **Very heavy usage** (500+ messages/day): Pollinations fallback activates (unlimited)
